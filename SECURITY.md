# Security policy

This repository holds the static home page and privacy policy of rclone-nas-backup. Only the latest commit of
`main`, which GitHub Pages serves, is supported.

## Reporting a vulnerability

Please report a suspected vulnerability privately rather than in a public issue.

- Preferred: GitHub's **Report a vulnerability** flow under the repository's
  [Security tab](https://github.com/VitaliiLazebnyi/rclone-nas-backup/security) (private vulnerability reporting).
- Alternatively, email <vitalii.lazebnyi.github@gmail.com> with the details.

Include a description of the issue, the affected page and, if possible, a minimal reproduction. You can expect a
first answer within seven days. Once a fix is merged and GitHub Pages serves it, the advisory is disclosed.
